# File Viewer Plus 支持的文件类型参考

> 数据来源：<https://fileviewerplus.com/file_types>（抓取于 2026-08-19，共 417 个条目 / 411 个唯一扩展名）
> 用途：Inf-Dir viewer 插件覆盖矩阵规划参考。6 个扩展名因同名不同格式各出现两次：`.dat`（Winmail/VCD）、`.cin`（Cineon/CIN 视频）、`.iss`（Funcom 音频/Inno Setup）、`.mpc`（Musepack/EA MPCh）、`.vb`（SIFF 视频/VBScript）、`.vhd`（虚拟硬盘/VHDL）。
